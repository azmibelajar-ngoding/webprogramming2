# webprogramming2
Ini adalah tugas 2 Pemrograman Berbasis Web | Pengenalan dan Praktek framework JS modern, vue.js.

Dalam tugas 2 ini, saya mempraktekkan penggunaan syntax kode Vue.js dalam pengaplikasikan para proyek simulasi web pemesanan bahan ajar SITTA yang biasanya menjadi kebutuhan pemesanan bahan ajar di UT.

Terdapat 3 poin penting dalam tugas 2 PBW ini:
1. directive v-text untuk menampilkan data
2. directive v-if dan directive v-else untuk pengkondisian data
3. data binding, menampilkan data di stock.html dan tracking.html dengan logika di javascript (stock.app.js dan tracking.app.js)

ini adalah struktur folder yang ada dalam proyek tugas 2 ini:

tugas2-vue-ut/index.html —————————— halaman depan dan navigasi Tracking dan Stok

tugas2-vue-ut/stock.html —————————  halaman yang menampilkan stok buku

tugas2-vue-ut/tracking.html ——————— halaman yang menampilkan data status pengiriman buku

tugas2-vue-ut/css/styles.css —————— untuk mengatur tampilan web

tugas2-vue-ut/js/stock.app.js ————— logika vue.js untuk stock.html

tugas2-vue-ut/js/tracking.app.js —— logika vue.js untuk tracking.html
